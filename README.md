# Mara Voss

A cinematic, editorial portfolio for an invented spatial architect. Built with Vite, React, TypeScript, TanStack Router v1, TailwindCSS, shadcn-style primitives, Lucide, and Zod.

## Run

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

The interface includes dark/light themes, English/Arabic direction switching, accessible contact validation, smooth anchor navigation, active-section tracking, project dialogs, tabs, accordion content, responsive layouts, and CSS-only motion.
